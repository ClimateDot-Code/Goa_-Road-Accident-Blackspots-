# Goa Road Accident Blackspots

This repository contains data and supporting materials for identifying road accident blackspots and accident-prone locations in Goa. The project focuses on geospatial analysis of traffic incidents to highlight areas with a high concentration of crashes and unsafe road conditions.

## Project Overview

The dataset and mapping files in this repository can be used to:

- identify accident-prone locations across Goa
- analyze crash patterns by location
- support road safety planning and policy decisions
- visualize blackspots using GIS tools and mapping software

## Included Files

- `Goa Road Accident data - Black Spots & Accident prone spots.csv`  
  Structured tabular data for accident and hotspot records.

- `Goa accident blackspots points.geojson`  
  GeoJSON dataset with point-based locations representing blackspot areas.

- `GitHub Documentation_Goa BlackSpots.docx`  
  Project documentation and analysis notes related to the Goa blackspot dataset.

## Use Cases

This repository is useful for:

- transportation and traffic analysis
- GIS mapping and spatial visualization
- road safety assessments
- academic projects and data exploration

## Suggested Workflow

1. Review the CSV file to inspect accident data fields and hotspot entries.
2. Load the GeoJSON file into QGIS, ArcGIS, or a geospatial Python workflow.
3. Cross-reference the documentation for context, methodology, and findings.
4. Use the mapped data to identify patterns and prioritize road safety interventions.

## Notes

This project is intended for analysis, research, and awareness around road safety in Goa. It may be used as a starting point for further analysis, dashboarding, or GIS-based study.
